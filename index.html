Panduan Integrasi GitHub Repository

Agar data tugas dan materi Anda tersimpan secara online di repository GitHub.

Informasi Akses: Website ini dapat diakses publik melalui HP/Laptop. Agar data tersimpan permanen di GitHub Anda sendiri, klik tombol "Konfigurasi GitHub" dan masukkan token akses Anda.
  1. Buat Repository di GitHub: Buat repository baru di akun GitHub Anda (misal: portal-tugas-marcell).
  2. Dapatkan Personal Access Token (PAT): Buat token di GitHub Settings > Developer Settings > Tokens dengan izin akses repo.
  3. Masukkan Konfigurasi: Klik tombol konfigurasi di kanan atas halaman ini, lalu isi Username, Nama Repository, dan Token Anda.
